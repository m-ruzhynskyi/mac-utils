# Текстовый редактор Mac Utils — ручной чек-лист приёмки

Данные: только эта папка (`Tests/Fixtures/TextEditor/`). Файлы пользователя не открывать.
Эталон для автопроверки — `expected.json` (генерируется `python3 -I make_fixtures.py`).
Файл 10 МБ: `./generate-big.sh /tmp/big-10mb.frm` (в репозиторий не класть).

Правило значения `$`: символы после `$` до пробельного (пробел, TAB, CR, LF), одного из `\ { } $ ;` или конца файла; значение может быть пустым.

Условные обозначения: Ф = фикстура, ✔ = ожидаемый результат. Номера смещений и значений см. в `expected.json`.

## Спорные места (решить с автором, пока трактуются как в `expected.json`)
- Юникодные пробельные (NBSP, U+2028) завершителем НЕ считаются: только пробел, TAB, CR, LF. Для `\f`, `\v` в `expected.json` нет случаев.
- «Убрать значение» у одного выбранного — допустимо и для приглушённых (пропущенных) вхождений; в `strip_single_text` есть все индексы.
- Единицы смещений: Unicode‑скаляры = UTF‑16 единицы (в фикстурах только BMP). CRLF — 2 символа.
- В `\ansicpg` и сохранении с «Преобразовать в…» тело RTF не переписывается автоматически.
