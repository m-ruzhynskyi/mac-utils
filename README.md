# Mac Utils

Набор утилит для macOS 14+ в одном фоновом приложении: без значка в Dock, с маленьким значком 🔧 в строке меню (его можно выключить; по желанию — и значок в Dock).

## Утилиты

| Утилита | Что делает |
|---|---|
| **Инструменты** (значок 🔧, ⌃⌥⌘T) | Панель со вкладками прямо под значком в строке меню: **Программы** — удаление приложения вместе с его данными, кэшем, настройками, контейнерами и автозапуском (всё в Корзину); **Монитор** — процессор, память, сеть, диск, батарея; **Задачи** — процессы с загрузкой и памятью, поиск, сортировка, завершение; **Очистка** — кэш, журналы, файлы Xcode, старые загрузки, Корзина; **Снимки** — поиск по своим снимкам; снимок можно скопировать или перетащить в любую программу. Те же инструменты — отдельными разделами в окне настроек. Вкладки панели настраиваются в отдельном разделе настроек «Панель в строке меню»: в неё можно вынести любой раздел Mac Utils (Встречи, Полка, Тёплый экран, Громкость…) и расставить вкладки в своём порядке (перетаскиванием или стрелками). Вкладки всегда в один ряд: если их больше пяти, остаются значки, а название вкладки появляется всплывающей подсказкой только при наведении и не занимает места. Есть и значок «Инструменты» в Программах / Launchpad. |
| **Снимки экрана** (по мотивам [macshot](https://github.com/sw33tLie/macshot)) | ⌘⇧X: область или окно (режим «Окно под курсором / Своя область» — кнопкой вверху экрана или Tab), стрелка, прямоугольник, карандаш, маркер, текст, нумерация, размытие; ручки размера у нарисованного, ⌘Z / ⌃Z и ⇧⌘Z. **F** — рамка окна macOS на градиентном фоне. **A** — «Шаг +»: коллаж шагов 1 2 3 (одинаковый размер, авто-сетка). **R** — запись области в MP4 или GIF (микрофон — с подавлением эха, звук системы не двоится). Длинный снимок с прокруткой. ⌘⇧⌥X — распознать текст. Сохранение в буфер, папку или туда и туда. **Умная папка**: снимки и записи экрана сохраняются в выбранную папку (по умолчанию Рабочий стол) в «Снимки экрана/дата/программа», текст на снимках распознаётся; всё видно и ищется в «Мои снимки» и во вкладке «Снимки» панели 🔧 (можно забирать и системные ⌘⇧3/4, скопированные только в буфер и уже сохранённые; старые — по желанию в Корзину через 7/30/90 дней). Клавиши работают в любой раскладке. |
| **Окна** | Перетащите окно к краю — половина экрана, к углу — четверть, к верху — весь экран. Сочетания ⌃⌥ + ←/→/↑/↓, U/I/J/K, ↩, C, ⌫; повтор переносит окно на следующий монитор. **⌃⌥P** — любое окно поверх всех: поверх остальных показывается его живая копия с настраиваемой прозрачностью, клик открывает настоящее окно. **Окна по мониторам**: при каждом наборе мониторов запоминается, где стояли окна, и при повторном подключении они встают на свои места. |
| **Фокус** (⌃⌥F) | Выбранная программа остаётся чёткой, а всё позади её окон — другие окна и рабочий стол, на всех мониторах — размывается и чуть затемняется. Включить: ⌃⌥F для активной программы (повторно — выключить) или «Выбрать программу…» в настройках → «Фокус». Там же сила размытия и режим «Следовать за активной программой». Когда работаете в другой программе, размытие прячется. |
| **Музыка** | Плеер в панели 🔧: что играет в любой программе (YouTube в браузере, Музыка, Spotify, Telegram…) — обложка, название, пауза, предыдущий/следующий, перемотка ползунком и ±15 с. |
| **Трансляция экрана** | Как в AnyDesk: у каждого постоянный 10-значный ID. «Начать трансляцию» — и по вашему ID к вам могут подключиться; каждого зрителя вы сначала разрешаете («Разрешить / Всегда разрешать / Отклонить»). История подключений с подписями и зелёной отметкой «в эфире»; можно смотреть друг друга одновременно. Зритель только смотрит из любой точки, где есть интернет, со звуком системы (по желанию; программы, чей звук не нужен зрителю, отмечаются в настройках «Не передавать звук программ» — глушатся и их помощники, например Discord Helper; вы их по-прежнему слышите). Перед стартом — выбор: весь экран, окно или программа (можно сменить на ходу). Видео идёт в аппаратном кодеке H.264 (как в Discord): 30 кадров в секунду, скорость сама подстраивается под сеть, задержка до секунды, в 5–8 раз меньше трафика и почти без нагрузки на процессор; зрителям со старой версией приложения дополнительно идут обычные кадры. При обрыве связи (смена сети, VPN, сон) эфир сам переподключается до 45 секунд, зрители ждут и видят «Ведущий переподключается…»; «Стоп» заканчивает эфир сразу. Для собеседника на Windows в разделе есть кнопка «Скопировать ссылку» на установщик — её можно переслать. Windows: приложение [Mac Utils Share](https://github.com/m-ruzhynskyi/mac-utils/releases/download/windows-latest/MacUtilsShare-Setup.exe) (ветка `windows`, обновляется само); в нём тоже можно не передавать звук выбранных программ (список — при старте и в любой момент эфира кнопкой «🔇 Звук»), а метки зрителей ложатся точно на транслируемое окно и не попадают в саму трансляцию. Чтобы выйти из просмотра чужой трансляции, не закрывая приложение, есть кнопка «Отключиться». В браузере трансляции недоступны — только в приложениях. Кадры идут через ретранслятор `relay/` (Cloudflare Workers) по зашифрованному соединению и нигде не сохраняются. Зрители могут кликнуть — на экране ведущего появится анимированная метка «сюда!» (как пинг в League of Legends) — или нарисовать линию; всё исчезает само через пару секунд (можно запретить). Если у ведущего несколько мониторов и он показывает экран целиком, зритель сам переключает, какой монитор смотреть: схема мониторов ведущего в панели просмотра, клик или клавиши 1–9, без вопроса; у ведущего на этом мониторе мелькает уведомление «‹имя› переключает на монитор N», в картинку оно не попадает (можно запретить: «Зрители могут переключать мои мониторы»; на Windows — галочка в «Что показывать?» и кнопка «🖥 Мониторы» в эфире). Ведущий и любой зритель могут сыграть в крестики-нолики: у зрителя кнопка «Сыграть» на панели меток, у ведущего — «Сыграть в крестики-нолики» напротив зрителя (на Windows — «＃ Сыграть» рядом со «Стоп»); ходы видят только эти двое, счёт ведётся. Зрители видят и интерфейс самого Mac Utils (скрыты только окно меток и индикатор «Эфир»). Маленький индикатор «Эфир» в углу экрана (наведите — зрители, «Стоп»). Пока открыто окно просмотра, Mac Utils виден в Dock и в ⌘Tab, а клик по значку выводит это окно. |
| **Рисование на экране** (⌃⌥A) | Стрелки, рамки, маркер и перо прямо поверх экрана во время созвона или записи (рисунки попадают в запись экрана). 1–4 — инструменты, ⌘Z — отменить, ⌫ — стереть, Esc — закончить; режим «исчезающих» штрихов. |
| **Перерывы и тёплый экран** | Каждые N минут работы — мягкий экран «встаньте, посмотрите вдаль» (отошли сами на 5 минут — отсчёт заново). Тёплый экран: свой Night Shift — по расписанию с плавным входом или вручную (кнопка ☀︎ в панели 🔧), отдельная сила для встроенного экрана и внешних мониторов. |
| **Записи встреч** (⌃⌥M) | Записывает звук созвона: собеседников и ваш микрофон отдельными дорожками. Расшифровка идёт прямо на Mac (русский, украинский, английский), затем локальная модель пишет отчёт: итог, решения, задачи, открытые вопросы. Можно расшифровать и готовую запись (аудио или видео, кнопка «Расшифровать файл…»). Всё сохраняется в «Документы/Встречи». Расшифровку делает Whisper (whisper.cpp, модель large-v3-turbo — ставится кнопкой в настройках: Homebrew + ~550 МБ; украинский, русский, английский, язык определяется сам) или встроенное распознавание Apple, отчёт — Ollama: итог, темы, решения, задачи, открытые вопросы. |
| **ИИ (Ollama)** | Всё на локальной модели (по умолчанию qwen2.5:7b), ничего не уходит в интернет. Модель загружается при первом запросе и выгружается из памяти через 5 минут простоя (~5 ГБ освобождается). **⌃⌥E** — исправить ошибки и опечатки в выделенном тексте. Умные имена снимков по распознанному тексту и поиск снимков по смыслу. «Загрузки»: папка для неизвестного типа и короткие английские подписи файлов во всех папках в комментарии Spotlight («📋 Spec — BHub Plan», «💿 Installer — Vorssaint»; видно в ⌘I и в колонке «Комментарии», ищется через ⌘Пробел). Диспетчер задач: что за процесс и можно ли его закрыть, категории списка. Очистка: что безопасно удалять и почему. Полка: группы файлов по смыслу. Модель выбирается и скачивается в настройках «ИИ (Ollama)». |
| **Переключатель окон** | ⌥Tab (или ⌘Tab вместо системного): по превью на каждое окно, как в Mission Control, без служебных окон; Q — завершить, H — скрыть. |
| **Громкость** (⌃⌥V) | Своя громкость 0–150 % и выключение звука для каждой программы; запоминается. Перехватываются только программы с громкостью не 100 %. |
| **Раскладка** (⌘] = ⌘Ъ) | Переводит последнее слово или выделенный текст между раскладками: ghbdtn → привет, руддщ → hello. Сочетание настраивается. **Раскладка по программам**: при смене программы включается её раскладка — запомненная (в Telegram была русская, в Терминале английская) или заданная правилом. |
| **Ввод текста** | Раздел настроек с переключателями автозамен macOS при наборе — для всех программ сразу: «Точка по двойному пробелу» (из-за неё после точки появляется лишний пробел — выключите), «Заглавная буква в начале предложения», автоисправление опечаток, подсказки слов в строке, «умные» кавычки и тире. Изменения действуют в новых окнах; в уже открытых программах — после их перезапуска. |
| **Полка** (⌃⌥D) | Временное место для файлов: перетаскивая файлы, встряхните мышь — рядом появится полка. Положите файлы, перейдите в нужное место и вытащите их по одному или все сразу (⌥ — оставить на полке). Полку можно двигать за заголовок. |
| **Шпаргалка** (удерживать ⌘) | Держите ⌘ около секунды — появятся все сочетания клавиш активной программы из её меню и сочетания Mac Utils; длинный список листается колесом мыши. Отпустите ⌘ — исчезнет (или включите «Оставлять открытой»: закрывается повторным ⌘ или Esc). |
| **Загрузки** | По желанию (выключено по умолчанию): новые файлы в «Загрузках» сами раскладываются по папкам Images, Documents, Archives, Installers, Video, Audio, Code и по вашим правилам «расширение → папка» (готовая категория, новая папка в «Загрузках» или любая папка на диске); старые через 7/30/90 дней уходят в Корзину (без безвозвратного удаления). Недокачанные файлы и ваши папки не трогаются. |
| **QR** (⌃⌥Q) | Выделен текст — показать его QR-код (скопировать / сохранить). Ничего не выделено — найти QR-коды на экране и скопировать их содержимое; ссылку можно сразу открыть. |
| **Вырезать и вставить в Finder** | ⌘X / ⌘V перемещают файлы; плавающая панель показывает, что вырезано. |
| **Плавная прокрутка** | Плавное колесо обычной мыши (в том числе через Logi Options+). Трекпад и Magic Mouse не затрагиваются. |

Всё включается, выключается и настраивается в окне настроек: значок 🔧 → ⚙︎, повторный запуск приложения или **⌃⌥⌘ ,**.

## Трансляция: проверка устройств

Чтобы никто не выдал себя за вас или за вашего зрителя, Mac Utils проверяет устройства ключом. Как это устроено — в [docs/SHARE-PROTOCOL.md](docs/SHARE-PROTOCOL.md).

* **Отпечаток устройства.** При первой трансляции или первом подключении Mac Utils создаёт ключ этого Mac. Ключ хранится в Связке ключей и никуда не передаётся.
  * Его короткий отпечаток вида `a1b2-c3d4-e5f6-0718` виден на странице «Трансляция экрана» («Отпечаток этого Mac») и в окне запроса зрителя.
  * Перед «Всегда разрешать» сверьте отпечаток с собеседником (в мессенджере или голосом).
  * Первое подключение закрепляет ваш ID за ключом: вести трансляцию с этим ID сможет только ваш Mac.
* **Доступ к Связке ключей.**
  * При первом ключе macOS спросит, можно ли Mac Utils пользоваться Связкой ключей. Ответьте «Всегда разрешать».
  * Сборки с постоянным сертификатом «Mac Utils Signing» больше не спрашивают. Сборки без сертификата (`./build.sh` с ad-hoc-подписью) спрашивают после каждой пересборки.
  * Если доступа нет и ваш ID ещё не привязан к ключу, трансляция работает без проверки ключа, как в прежних версиях. Если ID уже привязан (раньше доступ был), трансляция с этим ID не начнётся, пока доступ не вернут: Mac так и напишет. На странице трансляции будет написано «Нет доступа к Связке ключей, проверка ключа выключена». Временный ключ ваш ID не закрепляет.
* **«Получить новый ID».** Нужен, если появилось «Этот ID занят другим устройством». Так бывает после переустановки macOS, очистки Связки ключей или если ID успел занять кто-то другой.
  * Кнопка на странице «Трансляция экрана»: создаются новый ключ и новый ID. Если нажать её во время трансляции, старый ID сразу освобождается на сервере; иначе он остаётся за старым ключом и освободится сам через 180 дней без использования.
  * Старый ID вернуть нельзя. Сообщите новый ID зрителям, а тем, кто разрешал вас «всегда», — новый отпечаток.
* **«ID не подтверждён»** в запросе зрителя: названный ID закреплён за **другим** устройством. Возможно, кто-то представляется чужим ID.
  * «Всегда разрешать» в таком окне нет. Пускайте, только если уверены, кто это.
* **«Старая версия, личность не проверена»**: у зрителя приложение без проверки ключей (или ретранслятор её не поддерживает). Такие запросы всегда спрашиваются.
* **«Подтвердите один раз»**: зритель был в доверенных до проверки ключей. Сверьте отпечаток и нажмите «Разрешить и запомнить ключ».
* **«Ключ изменился»** у зрителя: у ведущего теперь другой ключ (переустановка, новый ID — или подмена). Подключайтесь, только если ведущий подтвердил, что это он.
* Mac Utils Share для Windows пока работает без ключа: его запросы помечаются «личность не проверена».

## Разрешения

| Разрешение | Для чего |
|---|---|
| Универсальный доступ | Перехват клавиш и колеса: Finder, прокрутка, переключатель, окна, раскладка, клавиши снимков, шпаргалка (чтение меню программ) |
| Запись экрана и системного звука | Снимки, запись экрана, превью окон, громкость приложений |
| Автоматизация → Finder | ⌘X / ⌘V в Finder (macOS спросит при первом использовании) |
| Полный доступ к диску | Удаление контейнеров программ из App Store (по желанию) |
| Микрофон | Только если включить запись микрофона в записи экрана |

Приложение подписывается постоянным сертификатом «Mac Utils Signing», поэтому разрешения не сбрасываются после обновлений. Сертификат создаётся один раз: `./scripts/make-signing-cert.sh`.

## Установка и обновления

Готовые версии — в [релизах](https://github.com/m-ruzhynskyi/mac-utils/releases): скачайте `MacUtils.zip` и перенесите `Mac Utils.app` в Программы. Дальше приложение обновляется само (раз в 6 часов или кнопкой «Проверить сейчас» в настройках → «Общие»); после обновления один раз показывает «Что нового», история версий — в настройках. Как нумеруются версии — в [docs/VERSIONING.md](docs/VERSIONING.md).

На другом Mac при первом запуске macOS может написать «Apple could not verify…» (приложение подписано своим сертификатом, без нотаризации Apple): Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть» (или `xattr -dr com.apple.quarantine "/Applications/Mac Utils.app"`). Если приложение запущено не из «Программ», оно само предложит перенестись туда — иначе не сможет обновляться.

## Разработка

Нужен Xcode 16+ (Swift 5.9+).

```bash
./build.sh            # собрать build/Mac Utils.app
./build.sh --install  # собрать, установить в /Applications и запустить
swift test            # тесты
```

Версию считает `scripts/version.sh`: локальная сборка получает канал `dev`, релиз выпускает только CI. Правила — в [docs/VERSIONING.md](docs/VERSIONING.md).

Ветки:

* **development** — основная ветка разработки. На каждый пуш GitHub Actions собирает приложение и запускает тесты.
* **main** — только через pull request из `development` с зелёными тестами. После слияния CI собирает универсальную подписанную версию и публикует релиз с `MacUtils.zip` и тегом `v…`; установленные копии подхватывают его автоматически.

Секреты репозитория для подписи релизов: `SIGNING_P12` (сертификат «Mac Utils Signing» в base64) и `SIGNING_PASSWORD`. Без них релиз не публикуется: неподписанное обновление сбросило бы разрешения.

## Ретранслятор трансляции

`relay/` — Cloudflare Worker с Durable Object на каждую комнату. Развернуть: `cd relay && npm install && npx wrangler login && npx wrangler deploy --var RELAY_COMMIT:$(git rev-parse --short HEAD)`, затем указать адрес в настройках «Трансляция экрана» (или вписать его по умолчанию в `Pref.shareServer`). Локально: `npx wrangler dev`. Тесты: `npm test --prefix relay`. Протокол, режимы проверки ключей (`AUTH_MODE`), лимиты, порядок выката и откат — в [docs/SHARE-PROTOCOL.md](docs/SHARE-PROTOCOL.md).
