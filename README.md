# Mac Utils

Набор утилит для macOS 14+ в одном фоновом приложении: без значка в Dock, с маленьким значком 🔧 в строке меню (его можно выключить).

## Утилиты

| Утилита | Что делает |
|---|---|
| **Инструменты** (значок 🔧, ⌃⌥⌘T) | Панель со вкладками прямо под значком в строке меню: **Программы** — удаление приложения вместе с его данными, кэшем, настройками, контейнерами и автозапуском (всё в Корзину); **Монитор** — процессор, память, сеть, диск, батарея; **Задачи** — процессы с загрузкой и памятью, поиск, сортировка, завершение; **Очистка** — кэш, журналы, файлы Xcode, старые загрузки, Корзина. Те же инструменты — отдельными разделами в окне настроек. Есть и значок «Инструменты» в Программах / Launchpad. |
| **Снимки экрана** (по мотивам [macshot](https://github.com/sw33tLie/macshot)) | ⌘⇧X: область или окно, стрелка, прямоугольник, карандаш, маркер, текст, нумерация, размытие; ручки размера у нарисованного, ⌘Z / ⌃Z и ⇧⌘Z. **F** — рамка окна macOS на градиентном фоне. **A** — «Шаг +»: коллаж шагов 1 2 3 (одинаковый размер, авто-сетка). **R** — запись области в MP4 или GIF. Длинный снимок с прокруткой. ⌘⇧⌥X — распознать текст. Сохранение в буфер, папку или туда и туда. Клавиши работают в любой раскладке. |
| **Окна** | Перетащите окно к краю — половина экрана, к углу — четверть, к верху — весь экран. Сочетания ⌃⌥ + ←/→/↑/↓, U/I/J/K, ↩, C, ⌫; повтор переносит окно на следующий монитор. |
| **Переключатель окон** | ⌥Tab (или ⌘Tab вместо системного): по превью на каждое окно, как в Mission Control, без служебных окон; Q — завершить, H — скрыть. |
| **Громкость** (⌃⌥V) | Своя громкость 0–150 % и выключение звука для каждой программы; запоминается. Перехватываются только программы с громкостью не 100 %. |
| **Раскладка** (⌘] = ⌘Ъ) | Переводит последнее слово или выделенный текст между раскладками: ghbdtn → привет, руддщ → hello. Сочетание настраивается. |
| **Вырезать и вставить в Finder** | ⌘X / ⌘V перемещают файлы; плавающая панель показывает, что вырезано. |
| **Плавная прокрутка** | Плавное колесо обычной мыши (в том числе через Logi Options+). Трекпад и Magic Mouse не затрагиваются. |

Всё включается, выключается и настраивается в окне настроек: значок 🔧 → ⚙︎, повторный запуск приложения или **⌃⌥⌘ ,**.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| ⌃⌥⌘T | Инструменты |
| ⌃⌥⌘ , | Настройки |
| ⌘⇧X / ⌘⇧⌥X | Снимок / распознать текст |
| ⌥Tab (или ⌘Tab) | Переключатель окон |
| ⌃⌥ + стрелки, U I J K, ↩, C, ⌫ | Раскладка окон |
| ⌃⌥V | Панель громкости |
| ⌘] (⌘Ъ) | Исправить раскладку |

## Разрешения

| Разрешение | Для чего |
|---|---|
| Универсальный доступ | Перехват клавиш и колеса: Finder, прокрутка, переключатель, окна, раскладка, клавиши снимков |
| Запись экрана и системного звука | Снимки, запись экрана, превью окон, громкость приложений |
| Автоматизация → Finder | ⌘X / ⌘V в Finder (macOS спросит при первом использовании) |
| Полный доступ к диску | Удаление контейнеров программ из App Store (по желанию) |
| Микрофон | Только если включить запись микрофона в записи экрана |

Приложение подписывается постоянным сертификатом «Mac Utils Signing», поэтому разрешения не сбрасываются после обновлений. Сертификат создаётся один раз: `./scripts/make-signing-cert.sh`.

## Установка и обновления

Готовые версии — в [релизах](https://github.com/m-ruzhynskyi/mac-utils/releases): скачайте `MacUtils.zip` и перенесите `Mac Utils.app` в Программы. Дальше приложение обновляется само (раз в 6 часов или кнопкой «Проверить сейчас» в настройках → «Общие»).

## Разработка

Нужен Xcode 16+ (Swift 5.9+).

```bash
./build.sh            # собрать build/Mac Utils.app
./build.sh --install  # собрать, установить в /Applications и запустить
swift test            # тесты
```

Версия — `1.2.<число коммитов>`, одинаково локально и в CI.

Ветки:

* **development** — основная ветка разработки. На каждый пуш GitHub Actions собирает приложение и запускает тесты.
* **main** — только через pull request из `development` с зелёными тестами. После слияния CI собирает универсальную подписанную версию и публикует релиз `v1.2.N` с `MacUtils.zip`; установленные копии подхватывают его автоматически.

Секреты репозитория для подписи релизов: `SIGNING_P12` (сертификат «Mac Utils Signing» в base64) и `SIGNING_PASSWORD`. Без них релиз не публикуется: неподписанное обновление сбросило бы разрешения.

## Устройство

```
Sources/MacUtils/
  App/        запуск, делегат, значок в строке меню, скрытое главное меню
  Core/       настройки, разрешения, event tap, горячие клавиши, уведомления, журнал
  Features/
    Tools/         панель «Инструменты»: монитор, диспетчер задач, очистка диска
    Uninstaller/   удаление программ и поиск их файлов
    Screenshot/    снимки, разметка, коллаж, рамка, запись экрана, длинный снимок, OCR
    WindowSnap/    раскладка окон
    AppSwitcher/   переключатель окон
    AppVolume/     громкость приложений (Core Audio process taps)
    LayoutFix/     исправление раскладки
    CutPaste/      ⌘X / ⌘V в Finder
    SmoothScroll/  плавная прокрутка
    Update/        автообновление из релизов GitHub
  UI/         окно настроек (SwiftUI)
Sources/ToolsLauncher/   значок «Инструменты» в Программах
Tests/MacUtilsTests/     модульные тесты
```

Журнал для отладки: `log stream --predicate 'subsystem == "com.mruzhynskyi.macutils"' --level debug`.
