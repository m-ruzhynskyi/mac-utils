# Mac Utils

Фоновое приложение для macOS 14+, которое не показывается ни в Dock, ни в строке меню и добавляет Mac четыре утилиты.

| Утилита | Что делает |
|---|---|
| **Вырезать и вставить в Finder** | ⌘X вырезает выделенные файлы, ⌘V перемещает их в открытую папку. Плавающая панель показывает, что вырезано. В текстовых полях (переименование, поиск) ⌘X/⌘V работают как обычно. |
| **Плавная прокрутка** | Колесо обычной мыши прокручивает плавно, с ускорением при быстром вращении. Трекпад и Magic Mouse не затрагиваются. Скорость и плавность настраиваются. |
| **Переключатель приложений** | ⌥Tab (или ⌘Tab вместо системного): превью окон с иконками в порядке последнего использования (превью требуют «Запись экрана»), Tab/⇧Tab/←/→ для выбора, Q завершить, H скрыть, Esc отмена. Разворачивает свёрнутые окна. |
| **Снимки экрана** (своя утилита по мотивам [macshot](https://github.com/sw33tLie/macshot)) | ⌘⇧X: выделение области или клик по окну, стрелка, прямоугольник, карандаш, маркер, текст, нумерация 1 2 3, размытие. Нарисованное перетаскивается, область двигается (V) и меняет размер за маркеры, Delete удаляет элемент. Длинный снимок с прокруткой: кнопка ⇕ на панели. Копирование/сохранение. ⌘⇧⌥X: распознать текст в области (русский, украинский, английский) и скопировать. |

## Как открыть настройки

Иконки нет, поэтому окно настроек открывается:

* повторным запуском приложения (двойной клик в «Программах», Spotlight, Launchpad);
* сочетанием **⌃⌥⌘ ,** (Control + Option + Command + запятая).

При первом запуске окно открывается само. Выйти из приложения можно кнопкой «Выйти из Mac Utils» в разделе «Общие» или ⌘Q в окне настроек.

## Сборка

Нужен Xcode 15+ или Command Line Tools со Swift 5.9+.

```bash
cd mac-utils
chmod +x build.sh
./build.sh --install     # собрать, положить в /Applications и запустить
```

`./build.sh` без параметров только собирает `build/Mac Utils.app`. Можно открыть `Package.swift` в Xcode и запускать оттуда.

## Автообновление через GitHub

1. Залейте код в публичный репозиторий GitHub, ветка `main`. GitHub Actions (`.github/workflows/build.yml`) на каждый пуш собирает приложение и публикует релиз `vX.Y.<номер сборки>` с `MacUtils.zip`.
2. Один раз выполните `./scripts/make-signing-cert.sh владелец/репозиторий` (нужен `gh auth login`). Скрипт создаст постоянный сертификат подписи, положит его в связку ключей и в секреты репозитория. Без него macOS будет сбрасывать разрешения после каждого обновления.
3. Установите приложение из первого релиза (или соберите локально и укажите репозиторий в настройках → «Общие» → «Обновления»).

Дальше приложение раз в 6 часов проверяет последний релиз, скачивает его, заменяет себя и перезапускается. Проверить вручную можно кнопкой «Проверить сейчас». Для приватного репозитория обновления не работают: API GitHub отдаёт релизы только с токеном.

## Разрешения

| Разрешение | Для чего |
|---|---|
| Универсальный доступ | ⌘X/⌘V в Finder, плавная прокрутка, переключатель |
| Запись экрана | Снимки экрана |
| Автоматизация → Finder | macOS спросит при первом ⌘X; нужно, чтобы узнать выделенные файлы и открытую папку |

Приложение подписывается ad-hoc, поэтому после каждой пересборки macOS может считать его новым: если утилита перестала работать, удалите Mac Utils из списка «Универсальный доступ» и добавьте снова. Чтобы этого избежать, подпишите своим сертификатом: `SIGN_IDENTITY="Apple Development: …" ./build.sh --install`.

## Устройство

```
Sources/MacUtils/
  App/        запуск, делегат, скрытое главное меню
  Core/       настройки, разрешения, event tap, горячие клавиши, уведомления
  Features/
    CutPaste/      ⌘X/⌘V в Finder и плавающая панель
    SmoothScroll/  плавная прокрутка
    AppSwitcher/   переключатель приложений
    Screenshot/    захват (ScreenCaptureKit), разметка, OCR (Vision)
  UI/         окно настроек (SwiftUI)
```

* `LSUIElement = true` в `Info.plist` убирает иконку из Dock и строки меню.
* Клавиши и колесо перехватываются через `CGEventTap`, горячие клавиши снимков и настроек через Carbon `RegisterEventHotKey`.
* Замена системного ⌘Tab использует закрытую функцию `CGSSetSymbolicHotKeyEnabled`; при выходе приложение возвращает системный переключатель.
