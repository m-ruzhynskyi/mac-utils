# Mac Utils

Набор утилит для macOS 14+ в одном фоновом приложении: без значка в Dock, с маленьким значком 🔧 в строке меню (его можно выключить).

## Утилиты

| Утилита | Что делает |
|---|---|
| **Инструменты** (значок 🔧, ⌃⌥⌘T) | Панель со вкладками прямо под значком в строке меню: **Программы** — удаление приложения вместе с его данными, кэшем, настройками, контейнерами и автозапуском (всё в Корзину); **Монитор** — процессор, память, сеть, диск, батарея; **Задачи** — процессы с загрузкой и памятью, поиск, сортировка, завершение; **Очистка** — кэш, журналы, файлы Xcode, старые загрузки, Корзина; **Снимки** — поиск по своим снимкам. Те же инструменты — отдельными разделами в окне настроек. Есть и значок «Инструменты» в Программах / Launchpad. |
| **Снимки экрана** (по мотивам [macshot](https://github.com/sw33tLie/macshot)) | ⌘⇧X: область или окно, стрелка, прямоугольник, карандаш, маркер, текст, нумерация, размытие; ручки размера у нарисованного, ⌘Z / ⌃Z и ⇧⌘Z. **F** — рамка окна macOS на градиентном фоне. **A** — «Шаг +»: коллаж шагов 1 2 3 (одинаковый размер, авто-сетка). **R** — запись области в MP4 или GIF. Длинный снимок с прокруткой. ⌘⇧⌥X — распознать текст. Сохранение в буфер, папку или туда и туда. **Умная папка**: снимки и записи экрана сохраняются в выбранную папку (по умолчанию Рабочий стол) в «Снимки экрана/дата/программа», текст на снимках распознаётся; всё видно и ищется в «Мои снимки» и во вкладке «Снимки» панели 🔧 (можно забирать и системные ⌘⇧3/4, скопированные только в буфер и уже сохранённые; старые — по желанию в Корзину через 7/30/90 дней). Клавиши работают в любой раскладке. |
| **Окна** | Перетащите окно к краю — половина экрана, к углу — четверть, к верху — весь экран. Сочетания ⌃⌥ + ←/→/↑/↓, U/I/J/K, ↩, C, ⌫; повтор переносит окно на следующий монитор. **⌃⌥P** — любое окно поверх всех: поверх остальных показывается его живая копия с настраиваемой прозрачностью, клик открывает настоящее окно. **Окна по мониторам**: при каждом наборе мониторов запоминается, где стояли окна, и при повторном подключении они встают на свои места. |
| **Рисование на экране** (⌃⌥A) | Стрелки, рамки, маркер и перо прямо поверх экрана во время созвона или записи (рисунки попадают в запись экрана). 1–4 — инструменты, ⌘Z — отменить, ⌫ — стереть, Esc — закончить; режим «исчезающих» штрихов. |
| **Перерывы и тёплый экран** | Каждые N минут работы — мягкий экран «встаньте, посмотрите вдаль» (отошли сами на 5 минут — отсчёт заново). Тёплый экран вечером: свой Night Shift с плавным входом по времени и отдельной силой для встроенного экрана и внешних мониторов. |
| **Записи встреч** (⌃⌥M) | Записывает звук созвона: собеседников и ваш микрофон отдельными дорожками. Расшифровка идёт прямо на Mac (русский, украинский, английский), затем локальная модель пишет отчёт: итог, решения, задачи, открытые вопросы. Можно расшифровать и готовую запись (аудио или видео, кнопка «Расшифровать файл…»). Всё сохраняется в «Документы/Встречи». Расшифровку делает встроенное распознавание речи Apple, отчёт — Ollama. |
| **ИИ (Ollama)** | Всё на локальной модели (по умолчанию qwen2.5:7b), ничего не уходит в интернет. **⌃⌥E** — исправить ошибки и опечатки в выделенном тексте. Умные имена снимков по распознанному тексту и поиск снимков по смыслу. «Загрузки»: папка для неизвестного типа и описания документов в комментарии Spotlight («📋 ТЗ — техзадание на …», «🧾 Счёт — …»; видно в ⌘I, ищется через ⌘Пробел). Диспетчер задач: что за процесс и можно ли его закрыть, категории списка. Очистка: что безопасно удалять и почему. Полка: группы файлов по смыслу. Модель выбирается и скачивается в настройках «ИИ (Ollama)». |
| **Переключатель окон** | ⌥Tab (или ⌘Tab вместо системного): по превью на каждое окно, как в Mission Control, без служебных окон; Q — завершить, H — скрыть. |
| **Громкость** (⌃⌥V) | Своя громкость 0–150 % и выключение звука для каждой программы; запоминается. Перехватываются только программы с громкостью не 100 %. |
| **Раскладка** (⌘] = ⌘Ъ) | Переводит последнее слово или выделенный текст между раскладками: ghbdtn → привет, руддщ → hello. Сочетание настраивается. **Раскладка по программам**: при смене программы включается её раскладка — запомненная (в Telegram была русская, в Терминале английская) или заданная правилом. |
| **Полка** (⌃⌥D) | Временное место для файлов: перетаскивая файлы, встряхните мышь — рядом появится полка. Положите файлы, перейдите в нужное место и вытащите их по одному или все сразу (⌥ — оставить на полке). |
| **Шпаргалка** (удерживать ⌘) | Держите ⌘ около секунды — появятся все сочетания клавиш активной программы из её меню и сочетания Mac Utils. Отпустите ⌘ — исчезнет. |
| **Загрузки** | По желанию (выключено по умолчанию): новые файлы в «Загрузках» сами раскладываются по папкам Images, Documents, Archives, Installers, Video, Audio, Code и по вашим правилам «расширение → папка» (готовая категория, новая папка в «Загрузках» или любая папка на диске); старые через 7/30/90 дней уходят в Корзину (без безвозвратного удаления). Недокачанные файлы и ваши папки не трогаются. |
| **QR** (⌃⌥Q) | Выделен текст — показать его QR-код (скопировать / сохранить). Ничего не выделено — найти QR-коды на экране и скопировать их содержимое; ссылку можно сразу открыть. |
| **Вырезать и вставить в Finder** | ⌘X / ⌘V перемещают файлы; плавающая панель показывает, что вырезано. |
| **Плавная прокрутка** | Плавное колесо обычной мыши (в том числе через Logi Options+). Трекпад и Magic Mouse не затрагиваются. |

Всё включается, выключается и настраивается в окне настроек: значок 🔧 → ⚙︎, повторный запуск приложения или **⌃⌥⌘ ,**.

## Разрешения

| Разрешение | Для чего |
|---|---|
| Универсальный доступ | Перехват клавиш и колеса: Finder, прокрутка, переключатель, окна, раскладка, клавиши снимков, шпаргалка (чтение меню программ) |
| Запись экрана и системного звука | Снимки, запись экрана, превью окон, громкость приложений |
| Автоматизация → Finder | ⌘X / ⌘V в Finder (macOS спросит при первом использовании) |
| Полный доступ к диску | Удаление контейнеров программ из App Store (по желанию) |
| Микрофон | Только если включить запись микрофона в записи экрана |

Приложение подписывается постоянным сертификатом «Mac Utils Signing», поэтому разрешения не сбрасываются после обновлений. Сертификат создаётся один раз: `./scripts/make-signing-cert.sh`.

## Установка и обновления

Готовые версии — в [релизах](https://github.com/m-ruzhynskyi/mac-utils/releases): скачайте `MacUtils.zip` и перенесите `Mac Utils.app` в Программы. Дальше приложение обновляется само (раз в 6 часов или кнопкой «Проверить сейчас» в настройках → «Общие»).

## Разработка

Нужен Xcode 16+ (Swift 5.9+).

```bash
./build.sh            # собрать build/Mac Utils.app
./build.sh --install  # собрать, установить в /Applications и запустить
swift test            # тесты
```

Версия — `1.2.<число коммитов>`, одинаково локально и в CI.

Ветки:

* **development** — основная ветка разработки. На каждый пуш GitHub Actions собирает приложение и запускает тесты.
* **main** — только через pull request из `development` с зелёными тестами. После слияния CI собирает универсальную подписанную версию и публикует релиз `v1.2.N` с `MacUtils.zip`; установленные копии подхватывают его автоматически.

Секреты репозитория для подписи релизов: `SIGNING_P12` (сертификат «Mac Utils Signing» в base64) и `SIGNING_PASSWORD`. Без них релиз не публикуется: неподписанное обновление сбросило бы разрешения.

## Устройство

```
Sources/MacUtils/
  App/        запуск, делегат, значок в строке меню, скрытое главное меню
  Core/       настройки, разрешения, event tap, горячие клавиши, уведомления, журнал, клиент Ollama
  Features/
    Tools/         панель «Инструменты»: монитор, диспетчер задач, очистка диска
    Uninstaller/   удаление программ и поиск их файлов
    Screenshot/    снимки, разметка, коллаж, рамка, запись экрана, длинный снимок, OCR
    WindowSnap/    раскладка окон, «поверх всех», окна по мониторам
    AppSwitcher/   переключатель окон
    AppVolume/     громкость приложений (Core Audio process taps)
    LayoutFix/     исправление раскладки
    DropShelf/     полка для файлов
    CheatSheet/    шпаргалка сочетаний клавиш
    DownloadsSorter/ автосортировка «Загрузок»
    QR/            мгновенный QR
    Annotate/      рисование поверх экрана
    Wellbeing/     перерывы и тёплый экран
    Meetings/      записи встреч, расшифровка и отчёт
    AI/            функции на локальной модели (Ollama)
    AppInputSource/ раскладка по программам
    CutPaste/      ⌘X / ⌘V в Finder
    SmoothScroll/  плавная прокрутка
    Update/        автообновление из релизов GitHub
  UI/         окно настроек (SwiftUI)
Sources/ToolsLauncher/   значок «Инструменты» в Программах
Tests/MacUtilsTests/     модульные тесты
```

Журнал для отладки: `log stream --predicate 'subsystem == "com.mruzhynskyi.macutils"' --level debug`.
